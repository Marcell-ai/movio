## Contributing

Movio is an open-source project, and we welcome contributions from the community. If you'd like to contribute, please follow these guidelines:

1. 🍴 Fork the repository.
2. ➕ Create a new branch for your feature or bug fix.
3. 🧑‍💻 Make your changes and run `bun run lint`, `bun run typecheck`, and `bun run test`.
4. 🧪 Run `bun run build` before submitting a pull request.
5. 📩 Submit a pull request, describing the changes you've made and why they're valuable.

I appreciate all kinds of contributions, including bug reports, feature requests, documentation improvements, and code enhancements.
